# Miguel Herrero

Independent systems researcher and builder based in Seville, Spain.

I build infrastructure for verifiable and resumable AI workflows. My current project is [HREVN](https://hrevn.com), a public-alpha integrity layer for signed checkpoints, structured evidence, and audit-ready workflow continuity.

## Focus

- durable and resumable workflow state
- tamper-evident evidence and provenance
- reconciliation across software and operational boundaries
- MCP and agent-tool integration
- explicit separation between executed evidence, source analysis, and architectural inference

## Selected public work

- [`hrevn-workflow`](https://github.com/ai-human-andalusia/hrevn-workflow) — local-first Python SDK for checkpoints, resume, artifact hashing, and workflow manifests
- [`hrevn-mcp-server`](https://github.com/ai-human-andalusia/hrevn-mcp-server) — thin MCP surface for the managed HREVN runtime

## Current research

I am studying the continuity and reconciliation problems that appear when a working proof of concept must become an operational system: durable state, retries, finality, external ledgers, evidence provenance, and recovery after partial execution.
